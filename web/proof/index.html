Reproduce

Use the tracked README flow to rerun the checks.

The commands below reproduce the bounded tests and resume the verified public devnet deployment with its finalized demo mints.

npm test
npm run bench:bounds
CALLWINDOW_CLUSTER=devnet \
CALLWINDOW_BASE_MINT=B6ZoEr92PB58bN1MgTXwjZHBUxCZ895ERVdhFJtSQFcP \
CALLWINDOW_QUOTE_MINT=7gLQ8vdtYTxbHa4YK9gjjsVe49WiKeH6pi2pV8us8zd4 \
CALLWINDOW_CUTOFF_SECONDS=240 npm run demo:devnet

The ignored `target/devnet/manifest.json` contains the complete 24-signature proof record. Devnet runs stop if the dedicated wallets are underfunded and do not request SOL from the public faucet.

This evidence proves

The demo mechanism works.

Funded demo orders can be bounded, closed at one deterministic price or refunded, claimed, and reconciled on localnet and public devnet.

This evidence does not prove

Live-market execution improvement.

It does not establish KALSHI fillability, eligibility, better execution, auction benefit, or that a real PreStocks token was auctioned. No mainnet deployment or trade occurred.

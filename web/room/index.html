How this room works

The link contains one auction address. Anyone opening it sees the verified Devnet account, exact demo mints, current orders, provisional result, and cutoff.

  1. 01
    Review the window

    Check the cutoff, funded buy and sell interest, and the provisional result.

  2. 02
    Prepare your wallet

    Use Devnet SOL for fees and rent. Claim demo assets once per wallet if available.

  3. 03
    Submit a funded order

    Buyers escrow DEMO-USD. Sellers escrow DEMO-EQUITY. Review before signing.

  4. 04
    Wait for the cutoff

    Orders can be added or cancelled before the cutoff, so the preview can change.

  5. 05
    Close, then settle

    After cutoff, any Devnet wallet can close the window. Owners then claim matched assets or refunds.

This page never auctions a PreStocks token or submits a mainnet transaction. DEMO-EQUITY and DEMO-USD are Devnet test assets with no PreStocks backing or monetary value.
